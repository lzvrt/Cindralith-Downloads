# Cindralith

Minecraft-лаунчер для Windows x64 и сборка Cindralith Tale.

**[Скачать установщик лаунчера](https://github.com/lzvrt/Cindralith-Downloads/releases/latest/download/Cindralith-Setup.exe)**

1. Запусти установщик. Он создаст ярлыки на рабочем столе и в меню «Пуск».
2. Открой Cindralith и нажми «Установить сборку». Java и игровые файлы скачаются и распакуются автоматически.
3. Для установки и обновлений аккаунт GitHub не нужен.

Лаунчер сообщает о новых версиях и по умолчанию обновляется автоматически после закрытия игры. Галочку можно выключить в настройках. Обновления Cindralith Tale устанавливаются кнопкой «Обновить» на странице сборки.

Свои сборки можно создавать, импортировать, переименовывать и снабжать иконками. При удалении профиля файлы и миры сохраняются в резервной копии. Встроенная Cindralith Tale всегда остаётся в списке.

Этот репозиторий содержит готовые установщики, игровые архивы, контрольные суммы и описания версий. Исходные проекты не публикуются здесь.

Все выпуски: [Releases](https://github.com/lzvrt/Cindralith-Downloads/releases). Установщик пока без цифровой подписи издателя. Лицензии сторонних компонентов находятся в приложении и игровых архивах.
